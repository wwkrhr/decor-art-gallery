# 装饰画芯展示

手机端装饰画画芯图册，纯静态网页，无需登录、无需安装。

## 访问地址

开启 GitHub Pages 后：https://wwkrhr.github.io/decor-art-gallery/

## 页面

- 首页：轮播 + 22 个分类 + 最近更新
- 详细分类：全部分类 + 主题合集
- 其他月份更新：按月归档
- 画芯列表：支持按编号 / 名称搜索
- 画芯详情：左右滑动切图，长按保存

## 目录

```
index.html    入口
app.css       样式
app.js        路由和渲染
data.js       数据（分类、月份、画芯）
assets/
  images/     图片
  icons/      底部标签图标
```

## 说明

这是**静态版**，数据写在 `data.js` 里，加图需要重新生成并上传文件，不能在网页上直接加。

本地源文件：`D:\个人成长\05 商业变现\02 产品与服务\装饰画程序\h5`
生成命令：`node scripts/build_h5.mjs`
